# Sealos

Sealos is a cloud operating system for developers and teams.

With Sealos, you can create projects, deploy applications from GitHub with one click, connect databases, manage public access, and inspect logs, metrics, and runtime status from one workspace. It brings development, deployment, and day-to-day operations into the same product, so teams can move from idea to running service with less friction.

Sealos is built for teams working on web apps, AI apps, internal tools, and data services. You do not need to assemble a full infrastructure stack before you start, and you do not need to jump between separate consoles for every small task. Connecting a GitHub repository, creating resources, checking status, and troubleshooting all happen inside the project.

Each Sealos project gives you a shared view of the resources behind your service. Applications, databases, public addresses, and deployment progress stay in context. You can see what is running, how it is exposed, which deployment is still in progress, and where to continue when something fails.

Sealos aims to make cloud work feel closer to product work: faster to start, easier to understand, and easier to keep running.
