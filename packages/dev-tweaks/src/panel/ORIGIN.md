# Origin: DialKit (core + React)

This directory started as the core and React portions of DialKit, Josh
Puckett's real-time parameter-tweaking panel, and is now maintained as our
own code — a hard fork. We do not sync with upstream; edit freely under the
normal workspace toolchain (tsc, Biome, ESLint).

- **Forked from:** github.com/joshpuckett/dialkit (MIT — see `LICENSE`
  alongside, which must stay)
- **Upstream source path:** `src/` (React subset; the solid/svelte/vue
  adapters, tests, example app, and build configs were never brought over)
- **Fork point:** commit `9dd1c68e3850a92d8be4525fd3016e61329751b3` (v1.4.3),
  vendored 2026-08-19, absorbed as a fork 2026-08-20
